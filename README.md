# دعوة زفاف — أحمد و ألاء

دعوة زفاف عربية (RTL) بتصميم "Moonlit Garden" (أخضر زيتوني + عاجي + نحاسي)، جاهزة للنشر مجانًا على GitHub Pages.

كل الملفات في هذا المجلد على نفس المستوى (بدون مجلدات فرعية) لتسهيل الرفع على GitHub.

## الملفات
- `index.html` — الصفحة نفسها
- `style.css` — التصميم
- `script.js` — العدّاد، الموسيقى، دفتر الضيوف
- `ahmed-alaa.png` — صورتكم
- `music.m4a` — الأغنية

## المميزات
- شاشة افتتاحية بختم نباتي متحرك (اضغط لفتح الدعوة)
- أوراق متساقطة بخفة في الخلفية
- صورتكم في أعلى الصفحة
- عدّاد تنازلي ليوم الفرح
- بطاقة تفاصيل (تاريخ، وقت، قاعة، عنوان)
- دفتر ضيوف مباشر (Firebase) — راجع القسم أدناه لتفعيله
- زر تأكيد حضور (RSVP) قابل لربطه بأي فورم
- موسيقى خلفية تشتغل بعد فتح الدعوة
- متجاوب بالكامل مع الجوال
